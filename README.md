# عقارات العراق 🏘️

موقع إعلانات عقارات في العراق مبني بـ **React + Vite** (HTML / CSS / JavaScript).

## المميزات
- عرض إعلانات البيع والإيجار (بيوت، شقق، أراضي، فلل، محلات، مكاتب)
- بحث نصي + تصفية حسب المحافظة (19 محافظة)، نوع العقار، السعر، وعدد الغرف
- ترتيب حسب الأحدث / السعر / المساحة
- دعم الدينار العراقي والدولار
- صفحة تفاصيل مع زر اتصال مباشر وواتساب
- إضافة إعلان جديد مع رفع صورة (تُحفظ في المتصفح localStorage)
- المفضلة وإعلاناتي
- تصميم عربي RTL متجاوب مع الموبايل

## التشغيل
```bash
npm install
npm run dev      # تشغيل بيئة التطوير
npm run build    # بناء نسخة الإنتاج في مجلد dist
```

> ملاحظة: الإعلانات الجديدة محفوظة محلياً في المتصفح. لتشغيل الموقع لعدة مستخدمين يلزم ربطه بخادم وقاعدة بيانات (مثل Firebase أو Supabase).
